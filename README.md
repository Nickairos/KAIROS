# КАЙРОС v3.0

**Скачай -> Прикрепи -> Скомандуй -> Отправь**

Ты ставишь ИИ задачу — а он льёт воду, галлюцинирует и выдаёт гладкий, вежливый, но абсолютно бесполезный ответ. Знакомо?

КАЙРОС не просто отвечает — он твой спарринг-партнёр, который:
- не поддакивает и не льстит
- проверяет твою логику
- указывает на слабые места
- требует данные, если их не хватает


Результат — не «красивые ответы», а проверенные и правдивые решения.

## Как начать

1. **Скачай** файл `kairos_core.txt`.
2. **Прикрепи** его в новом чате с ИИ.
3. **Напиши** команду: `АКТИВИРОВАТЬ_КАЙРОС`.
4. **Отправь** всё одним пакетом.

Получив ответ: `Метод КАЙРОС активирован. Правила приняты. Жду вводную.` — начинай работу.

Просто задавай свои вопросы и ставь задачи. Кайрос сам обеспечит дисциплину проверки.

Инструкция и живые примеры — в [Руководстве Оператора КАЙРОС](KAIROS_User_Manual.md).  
Кому нужна более подробная инструкция по активации — открой [PDF-версию](KAIROS_User_Manual.pdf).
